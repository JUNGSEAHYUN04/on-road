On-Road (온로드)

보육원 아동·청소년 및 자립준비청년을 위한 AI 진로·자립 성장 코치

정책 정보를 찾고, 쉬운 말로 이해하고, 신청을 준비하고, 생활을 계획하는 과정을 하나의 흐름으로 연결하는 서비스입니다.

배경

보호종료를 앞두거나 이미 보호가 종료된 자립준비청년은 주거·교육·취업·생활비 등 다양한 지원정보를 직접 찾아야 합니다. 관련 제도와 정보가 여러 기관에 분산되어 있어 필요한 정보를 찾고 이해하는 과정이 복잡합니다.

On-Road는 이러한 문제를 해결하기 위해, 정형 데이터(정책 조건 필터링)와 AI(검색·설명·요약)를 역할을 나누어 활용합니다. AI가 자격 여부를 임의로 판단하지 않고, 사용자가 확인해야 할 조건과 선택지를 안내하는 것을 원칙으로 합니다.

핵심 기능
1. 정책 검색 (RAG)
정책 데이터 15~20개 기반 DB 구축 (원문 그대로 보존)
사용자 프로필(연령/지역) 1차 필터링 + RAG 검색 결합 (하이브리드 검색)
근거 문서 기반 답변 생성, hallucination 방지 로직 포함
2. 쉬운 말 변환
정책 원문 → 이해하기 쉬운 문장으로 변환
핵심조건(대상/금액/기간/신청방법) 누락 없이 검증
3. 생활비 배분 시뮬레이션
소득/지원금 입력 → 항목별 배분 → 부족 항목 판정
부족 항목 대안 배분 시나리오 자동 제안
부족 항목과 관련 정책 연결
4. 신청 준비 체크리스트
정책검색 결과 기반 → 신청 준비 단계 자동 생성
흐름: 정책 찾기 → 쉬운말 이해 → 체크리스트 준비 → (필요시) 시뮬레이션
